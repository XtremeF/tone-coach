# Tone Coach

Mandarin tone practice for a Phase 0 learner: hear a syllable or tone pair, say it, see your pitch contour against the target shape. Everything runs in the browser; nothing is uploaded.

Reference audio: [audio-cmn](https://github.com/hugolpz/audio-cmn) (CC BY-SA), syllables by Chen Wang, words by Yue Tan, curated by Hugo Lopez. This page keeps the credit and the same CC BY-SA terms for the audio.
